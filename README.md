**Tema do Projeto:** Filme Live-Action *Como Treinar o Seu Dragão*

---

## 📌 Sobre o Projeto

Este repositório contém a entrega da atividade prática das Aulas 01, 02 e 03 da disciplina de HTML e CSS. A página foi desenvolvida com foco no filme live-action de *Como Treinar o Seu Dragão*, apresentando a sinopse, comparações com a animação original e os personagens principais.

---

## 🎯 Conteúdos Aplicados

### Aula 01 — Introdução ao CSS
- Conexão entre HTML e CSS externo usando a tag `<link>`.
- Estruturação semântica do documento HTML.

### Aula 02 — Formatação com CSS
- Aplicação de cores temáticas (`background-color`, `color`).
- Ajustes de tipografia e tamanhos de fonte (`font-family`, `font-size`).
- Alinhamento de textos e formatação de imagens (`text-align`, `border-radius`).

### Aula 03 — Modelo de Caixa CSS (Box Model)
- Aplicação prática dos conceitos de Conteúdo, Padding, Border e Margin.
- Criação do cartão de apresentação estilizado com espaçamentos e bordas personalizadas.
